# 機能要件

既存のTODO一覧に、完了切り替え、削除、表示の絞り込みを追加する。

## 前提

- TICKET-001の実装・確認後に、`app/` とテストを引き継ぐ。追加・一覧表示・入力検証を維持する。
- データは引き続きメモリ内に保持する。

## 実装する機能

- 各TODOのチェックボックスで、完了と未完了を切り替える。
- 各TODOの削除ボタンで、その項目だけを削除する。
- 「すべて」「未完了」「完了」で絞り込み、未完了件数は全TODOから数える。
- 全体が0件なら「TODOはまだありません」、絞り込みで0件なら「該当するTODOはありません」と表示する。

# 個別合格条件

## CM-001

- TICKET-001の入力検証と追加・一覧表示の確認項目を再実行する。

## UI-001

- 375px、768px、1440pxの各表示幅で、完了切り替え、削除、絞り込みを操作できる。
- 100文字のTODOがある状態でも、各操作ボタンが隠れず、横スクロールが発生しない。

## FE-002

- A、B、CのうちBだけを完了にすると、未完了はA・C、完了はB。戻すと未完了はA・B・C、完了は空になる。
- 同じ内容のTODOが2件あっても、指定したIDの項目だけを切り替え・削除できる。
- 絞り込みを切り替えても、データと登録順は失われない。
- A、B、CのうちBだけが完了なら、どの絞り込みでも未完了件数は2件である。

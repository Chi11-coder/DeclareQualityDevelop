# 機能要件

TODOを追加し、登録順に表示する画面を作る。

## 前提

- 作業フォルダの `app/` に、HTML・CSS・JavaScriptで実装する。外部フレームワークとバックエンドAPIは使わない。
- JavaScriptはES Modulesに分け、Node.js標準のテスト機能で確認できる構成にする。
- データはメモリ内に保持する。再読込後の復元はTICKET-003で追加する。

## 実装する機能

- 追加ボタンまたはEnterキーで登録し、入力欄を空にする。
- 一意のIDを付けて未完了で追加し、登録順に表示する。
- TODOがない場合は「TODOはまだありません」と表示する。
- 不正な入力では、その理由を画面に表示する。

# 個別合格条件

## CM-001

- 初回は追加・一覧表示のテストを作り、次のチケットで再実行できるようにする。

## UI-001

- 375px、768px、1440pxの各表示幅で、入力欄と追加ボタンを操作でき、横スクロールが発生しない。
- 空白を含まない100文字のTODOが、一覧の幅をはみ出さず表示される。

## FE-001

- 前後の空白を除去した内容が1〜100文字であれば登録できる。文字数はUnicodeコードポイントで数える。
- 空入力、空白だけの入力、101文字の入力では、一覧を変更せずエラーを表示する。
- 内容が同じTODOも、別々のIDを持つ項目として登録できる。
- `<img src=x onerror=alert(1)>` を登録してもコードは実行されず、その文字列が表示される。
